# Changelog

## 0.1.0

- First version.
- `Equal Views: Enable` appends a side-car to the running VS Code workbench bundle.
- The side-car equalises the expanded views of the chosen regions and yields to a
  manual splitter drag until the region changes shape again.
- `Equal Views: Disable and Restore` puts the original bundle back.
- Re-applies itself after a VS Code update replaced the bundle.
